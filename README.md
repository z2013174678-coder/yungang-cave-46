# 云冈·第46窟剧本游介绍网站

## 打开方式

直接双击 `index.html` 即可进入封面首页，无需安装软件或连接网络。

## 网站内容

- 童趣云冈主题封面与原创主视觉
- 独立封面首页与五个清晰的网站入口
- “认识第46窟”故事与文化理念页面
- “选择角色”页面，可切换眼睛、耳朵和时间线索
- “试玩关卡”页面，可逐步体验五段实景旅程
- “观看宣传片”页面，可在线播放58秒完整项目宣传片
- “参与体验”页面，包含奖励、传播闭环、出发指南与体验票
- 所有内页均可点击“返回首页”，并支持浏览器返回键

## 文件说明

- `index.html`：封面首页
- `idea.html`：项目故事与文化理念
- `roles.html`：三种线索角色
- `journey.html`：五段游玩关卡
- `video.html`：完整宣传片播放与下载页面
- `experience.html`：奖励、参与方式与体验票
- `styles.css`：视觉样式与移动端适配
- `script.js`：角色、关卡和预约交互
- `assets/yungang-hero.png`：原创云冈主题主视觉
- `assets/video/`：网页优化版宣传片与视频封面
